# Sequence (Urutan)

Sequence adalah konsep dasar dalam algoritma di mana instruksi dijalankan secara berurutan dari atas ke bawah.

Komputer akan menjalankan perintah sesuai urutan yang diberikan.

---

# Contoh Kehidupan Sehari-hari

Mencuci tangan.

1. Buka keran air
2. Basahi tangan
3. Gunakan sabun
4. Gosok tangan
5. Bilas dengan air
6. Keringkan tangan

Jika urutan tidak benar, hasilnya tidak maksimal.

---

# Contoh Python

```python
print("Belajar Sequence")
print("1. Nyalakan komputer")
print("2. Buka aplikasi")
print("3. Mulai belajar Python")
```

---

# Output

```python
Belajar Sequence
1. Nyalakan komputer
2. Buka aplikasi
3. Mulai belajar Python
```

---

# Kesimpulan

Sequence membantu program berjalan secara teratur dan sesuai urutan langkah yang telah dibuat.
